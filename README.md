# MudLag

Калькулятор лаг-тайма и генератор записей для грязевого каротажа (mudlogging), американская система единиц.

**Открыть:** https://1mtulegenov.github.io/mudlag/

- Конструкция скважины и КНБК с эскизом
- Лаг-тайм, ходы, AV, полный цикл
- Прогноз выхода на проектный забой
- Записи шоу и шлама (RU/EN), журнал, пресеты
- 3D траектория по инклинометрии (CSV/TXT/LAS), минимальная кривизна
- DD-панель: вертикальный разрез, план, расстояние до плана, PTB, окно цели
- Несколько скважин в 3D: соседние стволы по X/Y или ΔN/ΔE, минимальное расстояние (антиколлизия)
- Работает офлайн, устанавливается как приложение
